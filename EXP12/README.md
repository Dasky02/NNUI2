# EXP12 - Lokální LLM pomocí Ollama

Experiment volá lokální Ollama API a porovnává pět konfigurací generování nad
jedním pevným promptem.

Spuštění:

```bash
/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 run_experiment.py
```

Hlavní výstupy:

- `EXP12/results/ollama_outputs.json`
- `EXP12/results/summary.csv`
- `experiment_12.md`
